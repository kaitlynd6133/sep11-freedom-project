## Content
For this freedom project I will be making a unicorn version of flappy birds. The function of this game isn't going to be like any other flappy bird games. There will be three levels and each levels gets more difficult for users to play. For this project I was required to tinker with tools that would help me with creating my game. Ive decided to use [kaboom](https://kaboomjs.com/) for my tool because I think it is most compatible for my game and I think that it'll help me code my game easier since it already has a flappy bird template. I tinkered with kaboom by going through their codes in their [playground](https://kaboomjs.com/play?example=add) section where it shows examples of different codes and testing out the functions of the code. I also watched some youtube tutorial videos to learn more about the tool.

### Tinkering
I learned how to view my game using `npm run dev`. I also went to look at the confetti section and learned that `addConfetti` makes the confetti shows up. I learned different components of kaboom like `spin`, `gravity`, `drag`. Moreover I watched a video about  [character movement](https://www.youtube.com/watch?v=n-q0pKGhxyw). In this video I learned about how to load a character sprite sheet using `loadSprite` as well as different character movements. Further more I also learn to use `speed` to adujust how fast an object ot character will be going, `oneKeyDown` to make a component function when users press arrow keys. With all this code that I learned, I used it on my IDE and tested it there. I added the confetti and replaced the bean sprite with a cat. Here is my code : [main.js](js/projects/sep11-freedom-project/tool/kab-tinker/src/main.js)

## Engineering Design Process
Im currently still tinkering with kaboom and trying to learn more about its functions so I can use them for my project. My next plan is to learn about the codes for the flappy bird template on kaboom and maybe watch another tutorial video. 

## Skills
Skills that I gained is Learning on my own and Embracing failure
### Learning On My Own
I had to learn different codes from kaboom on my own through memorizing how different codes work and watching videos on youtube. For example I didn't know how to add a character to my game at first but after skimming through the code in the kaboom playground section I learned to use `loadSprite` and added a cat.
### Embracing failure
While tinkering with my code, it took a long time for me to figure out how the codes work and I would keep on getting errors. For example after tinkering in my IDE with kaboom I couldn't view my game. Instead of just giving up, I read through their tutorial section of kaboom and realized that instead of using `http-server`, I had to use `npm run dev`. When I was adding my cat character, it kept on popping up two cats and after skimming through my code I realized I used `playeradd` two times.
